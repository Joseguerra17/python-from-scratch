# Python from Scratch 🐍

Repositorio donde documento mi proceso aprendiendo Python de forma autodidacta, con el objetivo de conseguir un puesto remoto como desarrollador junior.

Sigo el curso de fundamentos de **Soy Dalto** en YouTube, escribiendo cada ejercicio por mi cuenta (sin copiar/pegar) y agregando mis propios comentarios para reforzar lo aprendido.

## 🎯 Objetivo

Aprender Python desde cero hasta un nivel junior empleable, apuntando a vacantes remotas como **Desarrollador Python Junior** para empresas que operan en Chile.

## 📚 Progreso

- [x] Variables y tipos de datos básicos
- [x] Operadores de pertenencia (`in` / `not in`)
- [x] Concatenación y f-strings
- [x] Condicionales (`if` / `elif` / `else`)
- [x] Formato de strings (separadores de miles, decimales)
- [ ] Programación Orientada a Objetos (POO)
- [ ] Funciones
- [ ] Estructuras de datos avanzadas (listas, diccionarios, sets)
- [ ] Manejo de errores
- [ ] Algoritmos y estructuras de datos básicas

## 🛠️ Proyectos hechos por mi cuenta

Ejercicios resueltos sin seguir tutorial paso a paso, aplicando lo aprendido:

- **Calculadora de IMC**: calcula el Índice de Masa Corporal y clasifica el resultado según rangos de salud.
- **Estado Financiero Mensual**: calcula superávit, déficit o equilibrio a partir de ingresos y gastos por categoría.
- **Calculadora de tiempo al hablar**: calcula cuánto tardaría una persona en decir una frase, con condiciones especiales.

# Python from Scratch 🐍

Repositorio donde documento mi proceso aprendiendo Python de forma autodidacta, con el objetivo de conseguir un puesto remoto como desarrollador junior.

Sigo el curso de fundamentos de **Soy Dalto** en YouTube, escribiendo cada ejercicio por mi cuenta (sin copiar/pegar) y agregando mis propios comentarios para reforzar lo aprendido. También documento mi aprendizaje en una bitácora personal en Notion, con repaso espaciado de los conceptos que voy viendo.

## 🎯 Objetivo

Aprender Python desde cero hasta un nivel junior empleable, apuntando a vacantes remotas como **Desarrollador Python Junior** para empresas que operan en Chile.

## 🛠️ Proyectos hechos por mi cuenta

Ejercicios resueltos sin seguir tutorial paso a paso, aplicando lo aprendido:

- **Calculadora de IMC**: calcula el Índice de Masa Corporal y clasifica el resultado según rangos de salud.
- **Estado Financiero Mensual**: calcula superávit, déficit o equilibrio a partir de ingresos y gastos por categoría.
- **Calculadora de tiempo al hablar**: calcula cuánto tardaría una persona en decir una frase, con condiciones especiales.
- **Calculadora con menú de operaciones**: pide dos números y un operador (suma, resta, multiplicación, división, potencia) y devuelve el resultado.
- **Sistema de login simple**: valida usuario y contraseña con operadores lógicos, y da acceso a un menú de operaciones tras iniciar sesión.
- **Ejercicios de funciones + bucles + acumuladores**: varios ejercicios practicando el patrón `for + if + acumulador + return` (contar pares, filtrar aprobados, combinar listas relacionadas con `zip`/`enumerate`, entre otros).
- **Escritura de datos a archivo**: genera un archivo de texto con una lista de nombres y apellidos combinados desde dos listas.
